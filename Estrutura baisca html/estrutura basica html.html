Estrutura básica do HTML

O HTML (Hypertext Markup Language) é a linguagem de marcação utilizada para criar páginas web. Ele é composto por uma série de elementos que definem a estrutura e o conteúdo da página.

A estrutura básica de uma página HTML é composta por algumas tags essenciais, que são:

  • <!DOCTYPE html>: Declaração do tipo de documento, indicando que se trata de um documento HTML5.
  • <html>: Elemento raiz que envolve todo o conteúdo da página.
  • <head>: Contém informações sobre a página, como título, metadados e links para arquivos externos.
  • <title>: Define o título da página, que é exibido na aba do navegador.
  • <body>: Contém o conteúdo visível da página, como textos, imagens, links e outros elementos.
